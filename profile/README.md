## What we do

- **Integrations & data sync** — link tools together so the work that used to live in someone's head, inbox, or spreadsheet just happens.
- **Internal tools that fit** — built for how you work, not how a SaaS tool wants it to. [More →](https://codemyriad.io/services/internal-tools)
- **AI in the workflow** — agents built in, not bolted on the side. We handle the plumbing so it actually does something useful.
- **Software you own** — open-source foundations, self-hosted, no per-seat lock-in.
- **Local-first architecture** — data that lives on the device and syncs in the background. Teams keep working when the connection drops.

## How we work

- **Shaped engagements** — fixed time, flexible scope. Every engagement is split into stages you can ship or pause after. [Shape Up](https://basecamp.com/shapeup) keeps scope from creeping.
- **Right-sized** — we'll talk you out of the expensive thing when it's wrong. A static site instead of a CMS, JSON instead of a database.
- **Built alongside you** — same team, not client-and-agency. We hand over the code and docs when you're ready to run it yourself.
